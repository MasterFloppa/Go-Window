# Go Window

Finds the best time to go outside **inside the hours you are actually free**, for the next 3 days.
A local open-weight model (Gemma via Ollama) explains the plan; plain code decides it. Every time you
tell it how a walk felt, it learns your personal heat, air and rain limits.

Work in progress for the DEV Hacktoberfest Open-Source AI Challenge, Week 1: Touch Grass.
